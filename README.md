# 유튜브 새 영상 재생목록 자동 추가

구독한 유튜브 채널에 새 영상이 올라오면, 그 채널에 미리 짝지어 둔 재생목록에
자동으로 넣어 주는 개인용 도구다. 만든 사람 한 명이 자기 계정에서만 쓴다.

## 무엇을 하나

- 채널의 공개 피드를 주기적으로 읽어 새 영상을 찾는다.
- 설정에 적힌 채널↔재생목록 짝을 보고, 그 채널의 영상을 그 재생목록에 넣는다.
- 짝이 없는 채널은 넣지 않고 시작할 때 거절한다.

## 어떤 권한을 쓰나

유튜브 데이터 API 의 `https://www.googleapis.com/auth/youtube` 범위 하나를 쓴다.
이 권한으로 하는 일은 둘뿐이다.

- 로그인한 계정의 구독 채널 목록과 재생목록 목록을 읽는다.
- 지정한 재생목록에 영상을 추가한다.

영상을 지우거나, 재생목록을 만들거나 지우거나, 채널 설정을 바꾸지 않는다.

## 어디서 도나

만든 사람의 개인 리눅스 컴퓨터 한 대에서만 돈다. 서버에 올리거나 다른 사람에게
배포하지 않는다.
